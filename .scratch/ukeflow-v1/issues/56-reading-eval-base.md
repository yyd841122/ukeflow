# 56: 独奏谱读取评测底座——冻结真值 + 联合事件 F1 评分器

**What to build:** 读谱候选方案的**可比尺子**(ADR-0010 决策 1/2):①「已裁定评测集」——从 gs-aini(爱你不是两三天)印张选代表性页/段,以历史转录(484 音)+ 印张像素考古为底,逐项人工裁决后**版本冻结**(文件+哈希);历史转录中的争议项(39 的 8vs5/4vs7、@7.5/@9/@17/@17.5 堆vs单音、@9.5-10.5 休止、第 1 小节「0」列、杆底符杠存疑段)在此流程内终审或显式排除(排除项公布数量/类型,困难样本不得全排);②「联合事件 F1 评分器」——事件 = 弦品+起音拍位+节奏三件套全对才算 TP;计数单位/一对一对齐/容差固定(节奏有理数精确比,容差 <1/32 拍且小于最短相邻起音间隔之半;空间定位误差另报);③语义分层——印张符号层与「统一展开规则→播放事件」层分开计分,展开规则单源共享(×+指形展开规则对所有候选一致);④数据分「已裁定/待裁定/未覆盖」三类台账,待裁定项公布数量与覆盖率。

**范围纪律:** 评分器只管打分不管读取;不做任何候选路的适配;真值冻结后改动走版本号;pytest 入 check.sh。

**需要用户:** 争议项集中终审一轮(预计 6-8 项,按对照表式验收同法)。
