# 53: 预备数拍期显示首小节和弦——进曲前把手摆到位

**What to build:** 跟练预备数拍(4 拍倒计)期间,在倒计数字旁显示即将进曲的**第 1 小节和弦**(和弦名+指法小图;若首小节多和弦,按拍序列出),让玩家在倒计窗口内提前按好手型。进曲后即隐去,不残留。

**Motivation:** 用户 2026-10-30 验收 33/36 实弹时提出:倒计期间屏上没有「接下来按什么」,一进曲手忙脚乱;当晚报告最差三处=第 1 小节 1/2/3 拍全漏,首小节稳定丢拍与无预告直接相关。

**范围纪律:**
- **仅预备期显示**,曲头一过即隐——与已撤的「右栏常驻预告」(记忆 practice-ui-minimal,用户明确撤过)划清界限,不得借机复活常驻预告窗。
- 弹唱谱跟练先行(和弦锚数据现成:PlayStrumEvent 谱首小节的 chordAnchors/和弦表);四线谱跟练首小节是逐音非和弦,预告形态不同,本票不做(留 46 新手提示线考虑)。
- 倒计数字与预备拍声不动;评分校准采样(预备期扫四下)不受影响。

**测试缝:** 预备期页面状态含首小节和弦数据(控制器查询现成 prep 查询同款);进曲后预告消失;无预备(直接开播?)不显示。

**Blocked by:** 无

**Status:** done
