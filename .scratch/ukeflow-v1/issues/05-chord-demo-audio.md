# 05: 和弦示范音试听

**What to build:** 和弦详情页"试听"按钮:按和弦指法把应响的弦错峰拨响(琶音感),闷音弦正确跳过——新手点一下就知道"这个和弦本来听起来是什么样"。音源走 04 的合成管线,经音源接口与引擎解耦。

**Blocked by:** 02 和弦库浏览, 04 Karplus-Strong 拨弦合成器

**Status:** ready-for-agent

- [ ] 任一和弦详情页点"试听"即听到该和弦的和声音
- [ ] 按法含闷音/空弦的和弦发声正确(闷音跳过、空弦拨响)
- [ ] 无爆音、错峰节奏自然
- [ ] 音源经接口调用(后续示范试听工单可复用同一管线)
