## Comments

- 2026-10-19 (拷问会话): 调研实证（当日直连抓取）——曲谱图网零反爬：搜索 `/Search?keys=<URL编码>`（可带 cid 过滤大类），分类列表 `/qiyuequpu/youkelili/`（3 页约 86 首），翻页 `list_N.html`，详情 `/qiyuequpu/youkelili/{id}.html`；提取规则 = 正文区内 `/uploads/allimg/` 开头的 img（一谱 1–N 图）；HTML 标的 width 与实际文件分辨率不符，以文件为准（实测 958×1112 起，多模态识别够用）；WebView 干净（无广告联盟，百度分享挂件 + 灯箱脚本不挡正文）；谱为转载（部分带他站水印），弹唱/指弹四线谱/和弦简谱混排，全站无文本谱。**AI 转谱决策**：多模态 LLM App 直连（纯自用无后端），key 设置页自配，文案写明单首成本量级；产出必须过与自建谱相同的校验层，**未经校对不进曲库**；只转弹唱谱图片（四线谱/简谱图没有对应输出模型）；prompt 要求输出可过校验的 ChordPro（降号拼法、段落闭合、歌词逐字保留）。**明确不接入**：夸克文档（围墙花园：React 空壳 + 阿里 Baxia 风控 + 私有签名预览接口，直连与 Wayback 存档双死）；Ukulele Tabs ukuleletabs.org（PDF 直链零障碍但库小、美国民歌/圣诞/凯尔特、偏器乐，弹唱价值低）；91pu（形态未证实）与 ChordWiki（华语覆盖弱）挂观察。
