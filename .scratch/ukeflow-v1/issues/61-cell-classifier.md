## m0 oracle-glyph 天花板实验(**已收口 2026-11-03,判读不利**)

把**冻结评测集当正确字形**(adjudicated marks 即 oracle)喂回 50 的自动定位+
节奏解码 → `eval-joint`。结果:事件 F1 **0.1688 < 0.90** → A 档(只训字形)
不成立。证据与归因见 `docs/research/2026-11-03-m0-oracle-glyph-61.md`:
节奏解码近聋(111 对齐列时值全对 ≈10.8%,None 按 0 累加致拍位塌缩)、
定位层空洞(漏检列/空 attack/多余 attack 毒化小节尾)、48 幻影小节线
(gs-aini 副歌全链拍位 +4,59a 基线同带此伤)。V1→V2 梯度(0.1688→0.4715)
证明符杠读取是第一墙。原始产物 ~/ukeflow-sources/m0-61/(仓库外)。

## m1 接口与出题机(**纳入符杠版**:分类目标 = 字形 + 杆底符杠 + 列存在性)

- **分类目标扩容**(原 TAB 词表 {×, digit(fret 0..15), muted, empty} 不够):
  - 音位格:(拍位格×弦) → 字形词表照旧;
  - **节奏带:列级时值/梁结构作分类目标**(杆/尾/杠/点/无——50 的
    几何规则读数被替换,这是 m0 第一缺口的正面解法);
  - **列存在性/空列显式分类**(m0:漏检列在分类器外照样毒化拍位,
    「此格无列」必须是可判定的输出)。
- **时值三层口径**(routes-survey-61-pivot.md v2 §3,选向阶段钉死):
  训练标签=**印刷记谱值**(符杠编码),不是 56 持续窗(含 tie 合流、
  不可当符杠标签);展开到事件走 eval_expand 统一,各层不可互指。
- **「格子」实现定义**:48 骨架继承定位(**不学定位**——48 是几何候选非
  已验证网格),(拍位格×弦)+ 节奏带窗,窗宽/内边距/重叠规则实现时钉死,
  样例覆盖密集堆/偏移记号/贴邻八度点/密集符杠段。
- **分类器→事件接口**:替换 50 的「字形识别+时值读取」级;小节网格锚定
  与统一展开保留;输出 schema 兼容 `eval-joint` candidate;unknown/abstain
  显式落警告(ADR-0009 纪律),abstain 计入评测不剔除。旋律层词表
  {degree 1-7, 八度点, rest, unknown} 照旧后置,本轮不做。
- **合成出题机(前置闸,v2 survey §6)**:从**显式记谱表示**渲染(39 播放
  语义渲染器直改不够——直化三连音/排除静默记号是已知语义差)。首个交付=
  **覆盖审计清单(时值/连音/休止/技巧/八度/静默记号/列存在性的支持矩阵)
  + 真实对照谱例 + 小规模迁移结果**,不是先造上千张;替代数据方案
  (真实标注/裁片增强/冻结骨干)同场比价;真实 dev crops(gs-aini p0)
  **先行**定失败模式,出题机按实测失败模式调参;合成验证集按渲染参数分切。
