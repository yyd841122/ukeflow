# 09: 弹唱谱跟练核心界面(产品之魂)

**What to build:** 跟练页第一版:选一首内置弹唱谱→按当前 BPM 编译时间轴→以 ~16ms 轮询练习状态渲染:歌词随节拍滚动、当前行高亮、当前和弦名带指法小图高亮、当前拍扫弦箭头高亮、节拍声播放。一切时间只读引擎时钟;UI 是练习状态的薄渲染,无第二时间源。固定速度、从头到尾(控制与预告在 10)。这是 spec 的核心体验,真机演示是唯一有效验收。

**Blocked by:** 02 和弦库浏览, 03 节拍器页, 08 时间轴编译器+练习状态纯函数(核心缝)

**Status:** ready-for-agent

- [ ] 真机完整跟练《沧海一声笑》:音画同步目测无漂移(spike B 判据)
- [ ] 和弦指法小图随当前和弦正确切换
- [ ] 扫弦箭头与节拍声同源同刻
- [ ] UI 层无自计时的路径(对照 ADR-0005 评审)
- [ ] 真机演示通过(戴耳机/外放自听)
