# 60: 零训练摸底——PaddleOCR-VL-1.6 / Qwen3-VL-4B 本地裸测

**What to build:** 在 4060 Ti 8GB(WSL CUDA)上本地部署两个现成视觉模型,
对谱全了谱面做**零训练**裸测,产出「文档解析强 ≠ 谱面强」的实证锚
(ADR-0010 追记二)。定位=**候选筛选实验**(57/58 同风格),不是 61 的
增益对照锚(任务形态不同,直接对比无意义)。

**要点:**
- 模型:PaddleOCR-VL-1.6(0.9B)+ Qwen3-VL-4B;**钉死** checkpoint 版本/
  推理后端/预处理/分辨率上限/生成上限。
- 输入:整页 + 系统裁块两形态(57 的 vlm-prepare 输入制备复用)。
- 产出:①**供给事实**(实测峰值显存/RAM/吞吐/截断/实际处理分辨率——与
  输入分辨率分开记;供给失败与识别失败**分开记**);②裸输出的**可度量**
  覆盖度:四线 TAB 行是否可见/数字谱行度数读出率/杆底符杠是否体现为时值/
  幻觉率;错误按类计数,不合并平均。
