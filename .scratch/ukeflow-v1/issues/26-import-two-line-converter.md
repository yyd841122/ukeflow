# 26: 导入易用性:两行式谱 App 内直转(新手适用)

**What to build:** 网上(尤其中文圈)能搜到的谱绝大多数是「和弦悬在歌词行上方」的两行式排版(工单 16 真机验收时 Beat It 原始粘贴实证)。现状:直接粘贴解析出零和弦空谱(工单 16 已拦下并给可读报错),新手必须去 App 外找转换工具(Bandcentral/ChordSmith)或求人转——门槛过高。用户决策:后期改进,新手不适用是当前形态的主要缺陷。

改进方向:
- 导入页内置两行式→行内式转换:识别和弦行+宿主行,按列位插入 `[Chord]` 记号。转换规则已在工单 16 机检中用 Python 原型实证(①行首悬空的第一个和弦吸到行首——原谱缩进只是排版习惯;②行中和弦落单词中间时回退到词首),落地即迁进 Dart,转换后进既有 预览→命名→入库 流程,用户可对照原谱核对。
- 同音异名建议:和弦库根音只有降号拼法,谱面写 F#/C# 被拦时,报错直接建议「试试 Gb/Db」(升#降b同音映射)。
- (可选)粘贴内容像谱但无任何元数据时,给一行示例模板引导({title}/{tempo}/[C]歌词)。
