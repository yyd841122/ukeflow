# 37: 指弹谱数据源——guistudy(谱全了)调研结论与 GP 导入提案

**What to build:** 票 25 批量段四首听写初稿被真机耳朵否决(音调+节奏均不对),根因=无权威乐谱源的纯听写不可行(沧海能过是因有多源文字谱锚点,流行歌没有)。本票记录 guistudy.com(谱全了)调研结论,并提出正路:**Guitar Pro 文件导入**(用户自备 .gp 文件,本地解析→TabNote),附 ADR-0003 边界修订提案。**决策归维护者,先 triage 再动手。**

**调研记录(2026-10-23 服务端探查):**

- 站点:guistudy.com =「谱全了」,免费吉他/尤克里里谱站;尤区热门 50 首可见(天空之城/卡农/周杰伦系/老歌英文曲都有),按难度/风格/调弦筛选,分页 `?no=`;单曲页 `/ukulele/{id}`。
- 元数据公开:标题/歌手/调性/bpm/拍号/Capo/难度/类型,`format: "gp"`——**曲谱本体是 Guitar Pro 文件**。
- 搜索:`/searchResults?searchValue=...&type=ukulele`(服务端返回全量热门列表,筛选由前端 API 拉,深挖需逆向其 XHR)。
- **曲谱数据 = `.ibe` 加密容器**(如 `i.guistudy.com/file/gtp/sheet/...ibe`,HTTP 200 无鉴权直出,熵 7.95 = 强加密),由站方前端播放器解密渲染「数字谱」。页面 HTML 无可导入文本。
- **已排除的路:解密 .ibe 批量爬谱**——绕过技术保护措施,不做。站方「免费下载/打印」给的格式未验证(需登录流),若为 PDF 渲染谱则解析价值低。
- 站点对学习者的正确用法:**网页播放器本身就是权威对照源**(数字谱+循环+选起点),人工照录入或截图转录均以此为准。

**提案(按优先序):**

1. **近期零代码路**:用户在 guistudy 网页打开想学的曲子,截图数字谱发给 agent,agent 按图逐音录入 TabNote(音调节奏以站方谱为准)——适用该站任何曲子,含票 25 四首的重新录入。
2. **中期功能票(需 ADR-0008)**:GP 文件导入——用户自备 .gp3/.gp5/.gpx(来源合法即可:自己收藏/转谱作者分享/商店购买),App 本地解析旋律轨→TabNote(音高+时值全权威)。ADR-0003「指弹仅内置、导入排除」的论据(文本格式混乱)不适用 GP 二进制结构化格式,建议立 ADR-0008 修订。解析器为多会话工程(格式族/时值/反复/装饰音),建议先 spike 单轨旋律谱。
3. guistudy WebView 浏览源(票 28 cifraclub 模式):**对指弹无导入价值**(页面无谱面文本),不建议单独立票;若做,仅作发现/跳转。
