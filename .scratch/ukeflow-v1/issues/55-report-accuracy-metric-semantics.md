# 55: 评分报告「准确率」语义拆分——覆盖与合格分开报

**Status:** done

**What to build:** 报告页头部大数字现为「准确率」= 非「漏」格占比(踩上 18/40 = 45%),**「错」计入其中**;小节卡片同理(第 9 小节 4 格全红显示 4/4 棕色满格)。用户读到 45% 会理解为「对了 45%」,与体感冲突(10-31 验收现场用户原话「最终的结果大部分不太正确」的困惑来源之一)。

**改法:** 拆成两个数:覆盖 = 非「漏」占比(现有算法),合格 = 非「漏」且非「错」占比;头部大数字用合格,副行保留四色计数;小节卡片底色按合格率着色(全红不该是棕色满格)。

**范围纪律:** 仅改展示与统计口径,判定内核/报告数据结构零改动;backup/导出零改动(报告不落库)。

**测试缝:** report 组装测试补合格率字段;卡片底色映射测试按新口径。

**Blocked by:** 无
