# 03: 萱草花弹唱入库跟练(3/4 弹唱谱首例)

**Status:** ready-for-agent

**Blocked by:** 02

**What to build:** 把 `~/ukeflow-sources/vector-pages/xuancaohua*.html`(弹唱谱,
key=C **3/4**,♩=80,33 小节,主歌@1/副歌@17)转换为弹唱谱入库,真机弹唱跟练可弹。
复用票01 的解码器与已钉事实(spec 与票01「已钉事实」节,不再重复),弹唱谱特有:

1. **和弦轴**:每小节和弦名+指法图(C G Am Em F Dm G7 C Em7,全自然根音,
   和弦库白名单兼容,含 58① 教训的 F# 拦截不适用),落弹唱谱和弦序列;
2. **歌词**:两段逐字与音符 x 对位已实证(「遥遥的青山上萱草花开放」/
   「遥遥的天之涯萱草花绽放」),生成带段落结构(`{start_of_verse: 主歌}` 等)
   的 ChordPro;歌词提取自用户手动保存件(spec 边界条款);
3. **扫弦节奏型**:节奏带解码出 3/4 实际扫弦型,回填票02 的节奏型库;
4. **简谱旋律行**:弹唱谱是否携旋律参考行,按既有弹唱谱模型边界决定
   (模型没有就不造;需要参考可另走独奏谱组合视图,实现时定,不预设);
5. 入库形态:builtin `assets/charts/*.pro`(维护者审过源文件后入库,自用谱库
   既有惯例)或导入流,实现时按既有弹唱谱导入面定,不预设。

**体检闸弹唱侧规则:** 每小节拍数=3;每行歌词字数与音符列数对账(已证逐字对位);
和弦名全部命中和弦库(未命中=红旗);来历不明符号(反复/段落标注语义)显式落。

**验收:**

1. ChordPro 源过票02 校验(3/4);builtin 资产测试绿(如走 builtin);
2. 真机弹唱跟练可弹(用户上手验收):扫弦动作/歌词行高亮/段落推进,
   ♩=80,3/4 拍感正确(「蓬-嚓-嚓」);
3. 反复记号展开后全曲小节序列与原谱一致,展开映射留证据。

**Non-goals:** 简谱旋律发声(双轨混播是独奏谱概念);指弹化改编(语义错位,
grill Q4 已否决 (c) 路线);下载器/收件目录(票04)。
