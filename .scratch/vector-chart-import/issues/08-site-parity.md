**mini-grill 结果(2026-11-07,用户逐条确认):**

1. 染色照抄原站:配色与变色范围从用户视频帧取真实值,不自创

   **禁止 OEM innerWidth**),曲尾 = 流过最后一小节收(尾部余量已有,
   验收时核)——现状曲头未从 0 起、曲尾需复核
3. 保留起播 4 拍预备数(不跟原站默认关)
4. 点谱面跳播:这轮不做
5. 验收 = 网页版与 App 并排对比,除「整页多行 vs 单行流水」结构差异外,
   流动手感/变色/声音同步肉眼无差异

**范围:**

1. 弹奏染色:页面装载时建音符元素坐标索引(横带 svg 的 text/rect 按 x

   agent 拍板:如 16ms 内插或平台滚动动画),验收对照视频手感
3. 曲头左余量(Dart 宽度/3)+ 曲尾复核

**Non-goals:** 点选跳播、评分、整页多行结构、票07 已交付项(提示条/
双钮/节拍跟练)。

**OEM WebView 实测事实(2026-11-07,本机,WebView 97):**

- 高频 runJavaScript 会排队 jam(首几发后全丢);单发也可能被丢 →
  一切 JS 指令需幂等+重发自愈
- innerWidth 报值不可信(疑似物理像素或异常值),页面几何一律
  Dart 算好注入数字
- 3MB loadHtmlString 本机装载 ~3.4s;onPageFinished 不可靠
  (setNavigationDelegate 异步挂载赶不上首装载)→ 装载 future +
  1.5s 定时器三路就绪
- 原生 scrollTo/scrollBy(平台方法)可靠;position:fixed 图层
  滚动前不重绘、滚动后错位 → 播放头等覆盖物一律 Flutter 层画
- 横带视图 GlobalKey 单实例复用:空闲/运行两树槽重挂不重载
  (3MB 页只装一次);装载期白转圈遮罩

**验收:**

1. 并排对比网页版:流动手感/变色/同步肉眼无差异(Q5)
2. 曲头:弹奏点 0 在线上;曲尾:流过末小节收
3. 真机全链:装载转圈 → 曲头 0 落线 → 首音按拍流到线上 → 三检查点

4. flutter/pytest 全闸绿;染色有测试(列桶索引/改色指令幂等)

## Comments

### 2026-11-07 实现(agent)

**视频帧取样结论(拆帧逐帧像素取证,30fps,43-47s 连拍 15 帧):**

- 站方染色是**两态不是三态**:只有「当弹」拍位的品数字形变红,已弹
  与未弹**同色**(逐系统墨色直方图完全一致,无变灰/渐隐)。票面原设
  「已弹/当弹/未弹」三态中「已弹」一项被证伪,按视频实现两态。
- 高亮红 = **RGB(200,97,109)**(#C8616D),15 帧众数逐帧完全一致;
  与站方红线**同色**(线=字一个常量,本机 Flutter 线与页面 JS 染色
  共用 `faithfulHighlightRed`)。用户首测 (193,103,113) 为同源视频
  压缩抖动,以多帧众数为准。
- 变色范围 = **仅纯数字 text 且字号 ≥ 全页最大数字字号×0.9**(品数
  字 10.92px 入选);小节号 9.24px(比值 0.85)、和弦名(斜体
  Georgia)、PUA 字形(谱号/波音线)、谱线/符干/符梁 rects 全部排除
  ——与视频逐帧对照一致(符干符梁不随音符变红)。

**落地(与票面范围的对应):**

1. 染色:索引脚本**内联在横带页**(不经 JS 桥,OEM jam 面零):
   字体就绪后(`document.fonts.ready` + 2.5s 兜底)按「嵌套 svg 裁切
   片的盒包含元素中心」定属主片,strip x = 片 x + (中心 − 片左缘),
   按 Dart 算好的八分列网格(每小节 8 列)分桶。`UF.paint(n)` 绝对
   状态全量重刷 = 幂等,列变化率(~0.375s)经 JS 桥单发,丢发由下一
   列重发自愈;建索引前到达的指令进 pending。改色范围按视频两态。
   Python 镜像 + node 迷你 DOM 干跑双重验证(51 小节 542 个品数字
   恰好各入一桶,小节号/和弦名全排除)。
2. 逐帧平滑:16ms 轮询定时器 → **视图内置 ticker(vsync)**,拍位每
   帧按引擎时钟现算(ADR-0005 不破:时钟缝=控制器 visualNow 原样,
   页只在轮询里递会话锚)。原生 scrollTo 不变;同目标去重,暂停=
   时钟冻结零下发。轮询的逐帧抖动是上一版卡顿来源。
3. 曲头:左余量(视口宽/3)与曲尾右余量(视口宽×2/3)**烘进包装页
   padding**(Dart 注入数字,innerWidth 脚本删除)——scrollTo(0) 时
   曲头 0 恰在播放头线上,预备数拍期负拍钳 0 在线上等待;曲尾几何
   闭式:maxScroll = 横带宽,末拍触线而止。装载推迟到首个布局帧
   (余量要视口宽);视口宽变化(旋转/分屏)才付重装代价(装载代数
   门挡旧回调)。停止回闲时当弹列还原(paint(-1))。
