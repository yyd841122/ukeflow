# 07: 弹奏提示条 + 节拍跟练(导入谱面页新手跟弹)

**Status:** done

**What to build:** 用户 2026-11-07 提出(天空之城入库验收后):①弹奏提示条
——按时间从头到尾逐列显示该弹的弦/品,新手跟着弹;②开始跟练——可选
节拍声或伴奏声,带循环等会话操作。

**实现:**

- `play_hint_bar.dart`:`playHintAt(布局, 主轴拍位)` 纯函数(当列 =
  最后一个 ≤ 拍位的列拍;曲头后首列前 = 引导帧当列空/首列预亮;预备期
  null)+ `PlayHintBar` widget(头部 = 和弦名大字 + 第x小节·拍y + 扫弦
  徽标;弦格 ④③②① 与和弦图同序,当列实底点亮、下一列描边预亮、无音
  「—」)。只跟伴奏层(主轴)——双轨旋律轨是代唱不是用户该弹的。
- 节拍跟练:TabPracticeController `start(beatClicks:)`——正曲拍按小节
  强弱响 tick(strong/weak 预注入 warmup),逐音示范声不起;restart 沿用
  模式(实测抓出重开静默打回逐音的 bug)。页面 = 速度行尾「节拍跟练」
  chip(紧凑,开始钮一屏可达的既有锁定不破),选中即「开始跟练」标签。
- 播放头红线改 Flutter 覆盖层:OEM WebView 对 position:fixed 覆盖 div
  合成层滚动前不重绘、滚动后错位(像素探针实证),不依赖 WebView 内
  CSS 定位;红线贴视口左 1/3 与跟滚锚同位。

**验收(真机机检记录 2026-11-07):**

1. 节拍跟练起播:预备倒计 → 占位提示 → 正曲强弱 tick(假引擎测试锁
   调度:4 预备 count / 1 strong / 3 weak / 0 拨弦)+ 提示条逐列推进
   (占位 → 引导帧首列预亮 → 当列实底点亮,C 和弦 0003+卷弦徽标实证);
2. 伴奏声示范照旧(提示条与声源无关);循环/变速/暂停/回开头原样;
3. 播放头红线空闲即现、运行中两次像素探针同位(内容已滚动);
4. logcat E/flutter=0;flutter 1002 + pytest 257 全绿。

**Non-goals:** 麦克风收音评分(指弹跟练线无此前例,弹唱跟练评分不外
推);提示条在自绘横带的重复高亮(自绘已有当位覆盖层,提示条是补充)。
