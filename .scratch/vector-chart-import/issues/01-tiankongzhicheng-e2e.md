## 已钉事实(2026-11-05 考古,勿重复劳动)

`<svg class="at-surface-svg">`,每 svg = 一个谱表系统。**无脚本/无 base64/无嵌入 JSON**,
元素三类:`<text>`(全部语义文本)、`<rect>`(线/符干/符杠)、`<path>`(弧点/斜线/曲线)。

- **天空之城布局**:和弦名+和弦指法图(18.1px 宽网格+开放弦弧点)/小节号(9.24px)/

## 待钉解码规则(本票第一步,逐条以几何+听感对账后写死进单测)

1. 符杠组→时值换算(单杠=八分;符尾孤立音符的 path 形态识别;附点判定);
2. 幽灵符干语义:萱草花每拍「有数字符干+无数字符干」成对——延音/伴奏柱二选一,
   用歌词-音符数对账 + 已知旋律听感裁决(天空之城无此问题,逐弦数字自明);
3. 八度点口径:简谱基八度与 midi 换算(以和弦指法图与音域界内互证);
4. tie 曲线归属(同音延音合并 vs 照读不并,与 58 dolce 口径对齐);
5. 琶音波纹→roll(复用运行时 `ScoreStrumKind` 既有 roll);
6. 反复/段落展开:识谱源 measures 是平铺骨架(只有 number+startBeat),
   反复记号必须在解码期展开成实际小节序列,展开前后小节号映射留证据;
7. 多声部分配:哪些列归 melody 声部、哪些归 accompaniment(复用 49/50 既有
   双声部口径);柱式和弦同拍多音照落。
