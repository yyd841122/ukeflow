# PDF 式谱面是组合视图：引用既有三源，不造统一谱格式

「爱你不是两三天」独奏卡真机听验后方向变更（工单 37，2026-10-24）：要的是照权威印张的**四层对齐弹唱谱面**（和弦图+和弦名 / TAB 伴奏 / 简谱旋律 / 歌词，按谱表系统上下对齐），不是纯 TAB 伴奏卡。已录三层各司其职：TAB 伴奏=独奏版 496 音（E 调指形，拍格 0-108，主轴）、简谱旋律=纯旋律版 168 音（C 指位，恒等于主轴 -20 拍）、和弦行=照印张从台账落成拍锚数据（拍位+和弦名+指形，E 调）。决策：谱面视图是**视图层组合**——一份 Dart 常量组合定义引用既有谱卡 id + 和弦行，渲染与播放（跟随高亮、单轨伴奏示范、双轨混播）都以组合定义为准；**不造统一谱格式、不动 ADR-0003 两模型分界**。「统一成万能谱格式」的想法第二次被排除。

## Considered Options

- **扩 TabChart 或造统一谱格式**：ADR-0003 已排除一次；三源异构（逐音 vs 逐音+词 vs 拍锚和弦）强行统一只会造出谁都喂不饱的中间格式。再排除。
- **和弦层吃弹唱校准版 ChordPro**：C 调、小节级、无拍格，与 E 调拍格网格异调异格，硬对齐必错位；弹唱校准版继续服务弹唱跟练，两不相扰。否。

## Consequences

- 三源绑定含**恒定拍格偏移**（旋律层 = 独奏层 -20 拍），组合定义是唯一记录处；新增曲目逐首定偏移与绑定。
- **双轨混播的音高基准**：旋律层数据发声在 C 调、TAB 层在 E 调，混播时旋律轨播放侧 +4 半音合流 E 调（谱角标 1=E 照印张；简谱行只显度数，显示不受影响）；各谱卡单独跟练维持原调不动。
- 曲库新增**独奏谱类型**（工单 38）承载组合谱面，点开默认进谱面视图。
- 工单 37 挂起的 GP 导入 ADR 让渡 0008 编号，若立项顺延 0009。
