# 取谱源转向：Cifra Club 退役，改文本双源 + 图片源 AI 转谱

Cifra Club 通道（工单 17/27，真机验收过的完整管线）因**内容**而非工程原因退役删除：葡语界面无法辨认、内容吉他向、无 ukulele 版回退原版观感即吉他谱——对目标用户不可用，git 留底后全套删除。2026-10-19 调研修订了「中文谱站只有图片谱」的绝对结论：中文世界存在服务端渲染的文本和弦谱站（Guitarians，港台流行覆盖），因此搜索源定为三家——Guitarians（中文文本谱，直解析直跟练）、UkuTabs（英文文本谱，直解析；Cloudflare 在前，真机 WebView 验证不过即砍不硬上）、曲谱图网（中文图片谱，经「AI 转谱」兜底：多模态 LLM 转 ChordPro 草稿，**人工校对、过同一校验层后才入库**，仅弹唱谱图片）。反爬纪律不变：一切取数在 App 内 WebView 发生，禁服务端 HTTP 直连。

## Considered Options

- **保留并打磨 Cifra Club**：语言与覆盖是内容问题，工程打磨无解，弃。
- **等谱友圈 puyouquan.com**：开放结构化全谱 API、零反爬、规划了 uku 类型，是数据形态最理想的源——但全库 9 首、尤克里里 0 首，冷启动期不可依赖；进观察名单（定期查 `/api/pub/scores` total），起来即接。
- **全 AI 生成谱**（不抓站，直接让 LLM 出谱）：编配真实性无保证，弃；AI 只做「源站已有图片谱 → 文本」的转换，编配事实以源站为准。
- **Ukulele Tabs（PDF 直链）**：技术零障碍但库小、美国民歌/凯尔特偏器乐，弹唱价值低；**夸克文档**：围墙花园（空壳 + Baxia 风控 + 签名预览接口，直连与存档双死）。均不接。

## Consequences

- 删 Cifra Club 代码前，先摘出 cifra_extract 的**升降号归一逻辑**——和弦库根音只认降号拼法，而 Guitarians/UkuTabs 全是升号拼法，不归一几乎首首被白名单拦（工单 17 已踩过同一坑）。
- UkuTabs 过 Cloudflare 属推断，真机验证是工单 34 的闸门；歌词按源站原样入库（Guitarians 繁体、UkuTabs 中文歌拼音），不做简繁转换。
- AI 转谱引入 API key 与单首成本，且转谱质量未经真机验证——隔离在最后一张票（工单 35），手动触发 + 校对门控制成本与坏谱。
- Guitarians 服务端移调参数（`?targetKey=`）已探明，App 端移调 UI 后置；若谱友圈谱库起来，其结构化 API 优先于本 ADR 的三家组合。
