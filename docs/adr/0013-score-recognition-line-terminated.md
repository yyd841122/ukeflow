# 曲谱识别产线终止;歌曲唯一来源 = 在线一手数据抓取

2026-11-14 定向(用户拍板)。用户原话:把 PDF 这条线直接去除,不做了,以后
直接抓取需要的歌曲源码。

## 背景

- ADR-0008/0009/0010/0011 链:曲谱页(组合视图)← 识谱源 ← 印张识别
  (像素考古+人工逐位对照)。对照表走到《爱你不是两三天》b3;
  识谱评测线(VLM/zero-shot/m0→m1)有 56/58 收口结论,m1 未开工。
- ADR-0012(2026-11-08)已把在线一手数据(.ibe)定为主渠道,PDF/矢量两线
  「搁置」;流水谱线(票01-08)已全部落地收口。
- 用户实练表明:评分跟练是日常动线,PDF 产线的逐位对照费时费力,且唯一
  消费品(曲谱页)与在线一手数据功能重叠。

## 决策

1. **曲谱识别产线终止**(较 ADR-0012 的「搁置」升级为终止):印张识别/
   像素考古/对照表走查/校对台/识谱评测集全部停止,不再投工。相关工单
   39/52/56-62 结清或砍(56/58 已 done 存档;39/52/59/60/61/62 砍)。
2. **《爱你不是两三天》整曲删除**:弹唱谱资产、指弹谱×2(旋律/独奏)、
   内置组合定义条目全部移除;其 b3 读数定案(2026-11-14)随曲存档于票39。
3. **App 端曲谱页/识谱源导入面拆除另票**(票64):ScoreSheetPage/faithful
   视图/横带提示条/dual_track 合流、识谱源导入流、imported_solo 表
   (schema 迁移)。**不与删歌同批**——score_ir 类型/谱面排版被指弹轻改
   (活线)共用,拆除须先解耦,单独成票防误伤。拆除前该面为休眠:无入口
   数据、零维护。
4. **歌曲唯一来源 = 在线一手数据抓取**(票07,ADR-0012 渠道不变):搜索 →
   下载 → .ibe 解码 → 体检闸(票08)→ 流水谱跟练。
5. **图片谱线同步终止**(2026-11-14 用户拍板):查看器/内置图库(Big Big
   World 图片版)/相册入库/ImageCharts 表(schema v9 下线)/备份 image_charts
   段全部移除;AI 转谱(票35)失去上游一并砍。曲库类型目录收敛为三类:
   弹唱谱/指弹谱/独奏谱(独奏谱位待票64 后再议存废)。旧备份文件里的
   image_charts 段读取时静默丢弃(未知键前向兼容)。
6. **天空之城流水谱归指弹谱类**:曲库顶部特殊卡撤除,按实际曲谱类型
   (器乐独奏编配)入指弹谱列表;入口仍过换歌体检闸(票08),debug 构建的
   坏谱自检入口随迁列表底部。

## Consequences

- 谱面内核(score_sheet_layout/deriveNumberedNotes/点选缝)仍被指弹轻改
  消费,测试改用合成组合夹具保留(test/helpers/score_sheet_fixture.dart);
  仅曲谱页面的消费侧测试删除(play_hint_bar/score_sheet_page/exporter/
  materializer/dual_track)。
- 旧备份若含 imported_solo 行,票64 迁移时按「未知表忽略」语义处理。
- tools/(workbench/pdf_census/pypdfium2 venv)与 ~/ukeflow-sources 资产
  暂留不删(历史台账与评测集在票56/58 存档),重启须单独决策。
- GLOSSARY 识谱源/曲谱页等词条保留为历史语义,消费面拆除后按需标注退役。
