# 在线一手数据为曲谱来源主渠道;矢量谱页与 PDF 两线搁置

2026-11-08 定向(用户拍板)。参照实现:codex `E:\codexProjects\musicScore`(只读,
已按《天空之城》真机核验:152.8536585 秒全曲、声画同步)。

## 背景

- ADR-0011 定的**矢量谱页渠道**(收件目录+检测按钮+体检闸)与票组
  (`.scratch/vector-chart-import/` 01-04)**未开工**;PDF 识谱线此前已被
  ADR-0011 搁置(ADR-0009/0010 三方互证像素路线 F1≈0.16-0.19)。
- codex 参照实现跑通了**在线一手数据**全链:谱站(guistudy)搜索 → 曲页
  `sheetInfo.scoreUrl` → `.ibe`(XOR `guitartabspro`,偏移=文件长度%10,
  Brotli)→ 解码 JSON(**音符/时值/节拍的权威数据,非渲染几何**)→ 双产出
  (练习时间表+引擎谱)→ 流水谱。
- 本仓已按同源数据完成《天空之城》MVP:`lib/core/score/`(转换器,守门
  断言全保留)+ `lib/features/play/flowing*`(流水谱+KS 示范声),数据内置
  资产,回归闸 = codex 真机核验值(51/317/557/152.8536585s)。

## 决策

1. 曲谱来源主渠道 = **在线获取一手数据**(原站播放器数据通道);矢量谱页线
   (ADR-0011)与 PDF 识谱线(ADR-0009/0010)全部**搁置**;重启须单独决策
   (矢量页样本 `~/ukeflow-sources/vector-pages/`、PDF 管线、校对台资产保留不删)。
2. 获取链路以 codex 参照实现为准移植:搜索、曲页解析(`sheetInfo`,页 BPM
   覆盖文件标称速度)、有界下载代理(白名单/限长/无凭据)、导入守门
   (**不认识的记号明确拒绝**,绝不静默降级)、双产出。
3. 运输形态(应用内并链路 vs 沿 ADR-0011 的外部下载器+收件目录)**待定**;
   MVP 过渡 = 内置资产,不阻塞谱面/跟练迭代。
4. 换歌纪律:每首歌**逐首体检**,谱面信息(难度/类型/版本号)随曲存档,
   同曲不同编配按版本指纹区分。

## Considered Options

- **沿 ADR-0011 矢量谱线继续**:渲染几何(text/rect/path)坐标精确但**无
  语义数据**,坐标→音符仍要一套推断规则;一手数据直接给音符/时值,确定性
  碾压;→ 搁置。
- **PDF 线重启**:ADR-0011 已搁,不重复;→ 维持搁置。
- **自研在线通道**:搜索/代理/解码/守门 codex 已全链验证并真机核验,移植
  即得;→ 采纳移植。

## Consequences

- vector-chart-import 票组搁置;其「体检闸」思路已移植为 `.ibe` 导入守门
  (转换器守门断言)。
- 在线获取未并入前的过渡:内置资产单曲;收件目录/检测按钮/存档记账等
  ADR-0011 机制**不实现**(随搁置作废,重启时再议)。
- 谱面显示不变:流水谱(flowing)为主,ADR-0008 组合视图、ADR-0003 双模型
  不动;识别源从「PDF 位图/矢量几何」换成「一手数据」。
