# 矢量谱页为主曲谱来源渠道;PDF 识谱线搁置

2026-11-05 定向(grill 会话,用户逐项拍板,Q1-Q13 全记录见
`.scratch/vector-chart-import/spec.md`):曲谱获取主渠道改为**网页矢量谱页**——
谱面渲染器(alphaTab)整页渲染 HTML。实证两首样本(萱草花=弹唱谱 C 3/4 /
天空之城=指弹 TAB C 4/4,存 `~/ukeflow-sources/vector-pages/`):文件是纯矢量
几何(`<text>`/`<rect>`/`<path>`,无嵌入语义数据),坐标精确、解码确定性——与
PDF 像素识别(57 VLM 0.19 / 59a 规则 0.1589 / 61 oracle 天花板 0.1688 三方互证)
难度差一个数量级。这复活并改写了 58①「同编配结构化源不存在」的结论:站方确无
外发渠道,但**用户手动存页/外部下载器取渲染 div** 就是那条通道。

分工:**站点的搜索与下载归外部独立项目**(不在本仓库);本 App 只认「收件目录」
里的矢量谱页文件,界面「检测」按钮手动触发扫描(不做后台/开App即扫,用户
Q13 定),按文件指纹记账。矢量源信任等级(修订 ADR-0009「校对台人工逐位确认」
纪律,**仅限矢量源**,PDF 线纪律不变):解码输出过**体检闸**(每小节拍长闭合/
音域界内/和弦指法图对照/来历不明符号显式)→ 全绿自动入库,红旗只列疑点待
用户确认;原始 HTML 永久存档(存源模式,ADR-0009 同型),坏源 Broken 兜底。
运行时谱面模型不变(ADR-0003 双模型 + ADR-0008 组合视图),识谱源仍是导入谱
唯一真源——**不造第三种谱格式**的原则不动,变的只是「识别端输入」从位图换成
矢量几何。

## Considered Options

- **App 内联网采集(WebView 拉页→取 div)**:反爬/登录墙/网站改版三重风险,
  且把采集耦合进 App;→ 拆出独立下载器项目,App 只吃文件(用户 Q10 定)。
- **PDF 识谱线照跑(工单 60/61/62)**:矢量源确定性碾压像素猜测,两线并跑
  精力分散;→ 搁置(用户 Q11 定),遇「网上无源」的歌再议重启,须单独决策
  (ADR-0010 追记四)。
- **后台定时扫描收件目录**:Android 后台限制+自用场景收益小;→ 手动检测按钮
  (用户 Q13 定)。
- **弹唱谱 HTML 硬转指弹识谱源**:语义错位(弹唱谱无 TAB 声部);→ 拍号扩展+
  弹唱入库(票02/03)。
- **矢量源沿用全量人工逐位校对**:校对台纪律为不可靠识别而设,矢量源解码
  近乎无损;→ 体检闸自动放行+红旗人工(Q9 定),校对台资产保留供抽查复用。

## Consequences

- 新票组 `.scratch/vector-chart-import/`(spec+票01-04):01 天空之城端到端
  (PC 解码→识谱源→现有导入流→真机跟练)、02 拍号扩展(解除 assets/charts/README
  「v1 仅 4/4」约束,附格式 ADR)、03 萱草花弹唱入库、04 收件目录+检测按钮+
  判别+Dart 解析器移植。用户指令:先把这 2 首导入弹起来,确认可弹再通用化。
- 工单 60/61/62 搁置(票面加注,非 wontfix);ADR-0010 追记四记录;校对台/
  评分器/冻结评测集资产保留复用。
- 矢量源证据 = SVG 坐标 + 可选自渲染裁片;解码规则(幽灵符干/八度点口径/tie/
  琶音→roll/反复展开)在票01 钉死并落单测黄金断言,「已钉事实」清单随票存档。
- 下载器接口契约:一个 HTML 文件=一首曲=一个完整渲染块;歌名/署名/拍号/速度
  从谱面内容读,不依赖文件名;样本 UTF-16LE CRLF,解析器须兼容。
- 体检闸与 App 校验器规则镜像(同校对台 preflight→物化端的既有镜像关系),
  权威校验仍在物化端;「禁止静默丢符号」纪律升级为跨源铁律(PDF 与矢量源一致)。
