# gs-aini 300dpi 几何档案单表(工单50 retro)

识别工作台全部几何常量的**单一来源**:谱全了印张在 300dpi 渲染下的实测值,
一符号一行。两套历史单位在此统一——早期 census 走 scale3(弦距 14px),
工单48 起管线固定 300dpi(弦距 19.2-19.4px);**比例 1.37,跨文档读数先换算**。
所有值出自像素考古(工单39/41/48/49/50),改动须带新实测票据。

基准:弦距 g = 19.2px(300dpi);坐标向下,x 向右;①线=顶线。

## 谱表与骨架

| 项 | 值(300dpi) | 出处 |
|---|---|---|
| 谱线芯部灰度 | <195(与字形墨同档!分行须按 line_ys 删带,不能靠灰度) | 工单50 实测(scale3 时 210,比例失真) |
| 谱线间距 g | 19.2-19.4px(系统间漂移) | 工单48 |
| 行墨量判据 | 行墨 ≥30% 页宽(半幅末系统 0.43,歌词行 ≤0.25) | 工单48 |
| 小节线 | 贯穿谱高竖线,上下延 ≤0.5g;与箭头杆同厚(4-5px)不可分,靠「距小节界+无音位」排除 | 工单41/50 |
| 小节宽 | 逐小节不等宽(411-555px),px→拍标定不成立 | 工单41 |
| 谱号区 | 系统头 T-A-B 竖排字母(13×15×3)+ 4/4 拍号(行间空间),压线判据天然排除 | 工单50 |
| 逐符号 x 漂移 | ×/波浪右移 ~25px(0.24 拍),箭头/数字 ~0;拍位累加不吃 x 距离 | 工单41/50 |
