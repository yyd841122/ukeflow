# dolce 互证源集成方案(工单 59a 交付②,只定不实现)

2026-11-03。定位:第三环「混合读取+校对」里 dolce(悦谱)的角色落地——
58③ 判定已定案:**作旋律层引擎不可**(无坐标/无拍位骨架/八度点 ±1 不稳
≈12.6% 三硬伤),**作互证源成立且高价值**(度数/节奏/拍位 F1 0.84-0.86,
失配集中单一可解释模式)。本方案把它接进工单 51 校对台,目标只有一个:
**压校对工时**(产品总闸:单首 ≤30min/0 未解释差异;59b 将对现状计时,
本方案落地后同协议复测)。

边界(先钉死):

- dolce **不进读取引擎链**,不改 49/50 管线本体,不伪造 bbox/坐标
  (证据链契约不满足是 49 判其不可作引擎的根因,集成不假装解决);
- 一切并入动作是**行级人工采纳**,无全曲一键覆盖;
- 工作台内实验,ADR-0009 接入门不动(ADR-0010 决策 6);
- 变拍区/跨行续刀是 dolce 侧已知障碍(58③),本方案只做如实呈现,不解决。

## 1. 对齐契约(硬核:无 bbox 的音序对应)

dolce 输出 = 音乐行序列(行内小节→token,零坐标)。落进校对台按小节索引
的 IR,需要四层对应关系,逐层给契约:

| 层 | 对应 | 契约 | 已有件 |
|---|---|---|---|
| L1 行→系统 | dolce 存活行 ↔ layout 简谱带系统 | **保序枚举**:行 bar 数==系统 measure 数为硬约束;解可多个(等长小节段结构歧义),全部披露按内容择优 | `candidate_assignments`(58③) |
| L2 小节→小节 | 行内 bar ↔ 系统 measure | 1:1,随 L1 解确定 | 同上 |
| L3 拍位 | bar 内 token 累加 ↔ measure 内拍 | 小节网格锚定(小节序×拍号+bar 内拍);变拍区(布局累计号≠印张号)枚举无解→转人工锚 | `collect_line_attacks` + 灰字锚(start_bars) |
| L4 音↔IR 行 | dolce 攻击 ↔ 旋律音行 | 按(拍位,midi)落位,**不主张 1:1 配对**——dolce 行是 IR 行的来源之一,不是平行轨;两侧读数并排留痕 | `melody_score` 配对机制复用为对照器 |

**内容核对闸的产品化改造**:58③ 的双闸在有冻结真值的评测语境里成立;
产品语境(未见曲)没有真值,内容闸改为**跨源一致率**——dolce 行与 49
草稿逐音对照(melody_score 同函数),一致率低的行不自动采纳、整行转人工
(对照分歧本身就是校对热点清单)。结构闸照旧:L1 唯一解,或人工灰字锚。

## 2. 人工锚工作流

```
载入 page*.123 + layout.json(工作台新入口「dolce 对照」)
  → 抑制(58③ 判据,零误杀已实证;计数披露)
  → L1 结构枚举
      ├─ 唯一解 → 行状态=已落位,内容对照自动跑
      ├─ 多解   → 行状态=歧义,展示各解一致率,人点选
      └─ 无解   → 行状态=待锚,人按印张灰字小节号填「起始小节」
  → 逐行人工采纳(采纳=该行 dolce 读数落进对应段旋律层 IR,
      来源标记 dolce;不采纳的行保持 49 草稿原样)
  → 走既有逐小节确认 → preflight → 导出 ScoreIR(51 既有闸,不变)
```

锚(每行起始印张小节号)存进 proof.json 会话,重开不丢;来源路径
(`~/ukeflow-sources/<曲>/page*.123`,仓库外)也记进会话。

## 3. 不可对齐态的呈现(全量披露,无静默合并)

四态行徽标 + 顶部计数条(`3 行已采纳 · 1 行待锚 · 1 行歧义 · 1 行存疑`):

| 状态 | 判定 | 呈现 |
|---|---|---|
| 已落位 | L1 唯一解 | 可采纳;采纳前先看对照分歧 |
| 歧义 | L1 多解 | 列解集+各解一致率,点选后可采纳 |
| 待锚 | 枚举无解(变拍/行数不齐) | dolce 原文行显形 + 起始小节输入框 |
| 存疑 | 跨行续刀(行首未闭连线)/小节闭合≠拍号 | 整行黄标,默认不可采纳,须人工逐音 |

抑制掉的垃圾行不进四态,只在载入摘要给计数(TAB/和弦垃圾行,58③ 实测
零误杀)。

设计取舍(留作实现票决策点,本方案推荐前者):

- **行级采纳、双源可换底**:哪边当底稿逐行决定——dolce 段内 F1 高的行
  (主歌)用 dolce 预填省一半敲击;49 读得好的行(如 dolce 存疑行)保持
