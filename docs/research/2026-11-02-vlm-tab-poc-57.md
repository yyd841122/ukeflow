# VLM 直读 TAB POC——整页 vs 系统裁块对照(工单57,ADR-0010 主线实测)

日期:2026-11-02 · 样张:gs-aini(爱你不是两三天)谱全了印张 ·
评分尺:工单56 冻结评测集 `gs-aini-tab-v1`(payload sha256 `034d42c4…`)+
`eval-joint` 联合事件 F1 评分器(τ=1/32 拍,只评已裁定拍段)。

## 结论先行

1. **晋级线未过,且差一个数量级**:晋级线 = TAB 联合事件 F1 ≥ 0.90(ADR-0010
   决策 4)。实测整页 F1 = **0.1905**、裁块 F1 = **0.1924**(P/R ≈ 0.14-0.29)。
   Codex 立票先验(整页稳定过线先验 ≤25%)方向命中。
2. **「裁块破坏上下文」假设部分证伪**:裁块形态没有像 dolce 简谱裁条那样整体
   塌掉(事件 F1 0.19 vs 整页 0.19,基本打平;符号层裁块反而更好 0.30 vs
   0.19)。两形态各自以不同方式烂:裁块 = 漏读约 1/3 的音 + 拍位网格系统性
   漂移(±0.25 拍整);整页 = 大面积整段漏读(事件数 159 vs 真值 324,弦①
   崩得最狠)。
3. **「读对音、读错拍」是主要失败形态**:候选事件的 (弦,品) 多重集命中率
   (对候选)裁块 0.916 / 整页 0.950——读出来的音大多是真音;但对真值的覆盖
   只有 0.64 / 0.47,且拍位配不中。**主要瓶颈 = 节奏网格重建,不是音高识别**。
4. 本轮为否定性结论但**证据充分**(非「预算烧完=证据不足」):9 次调用共
   **¥0.84**(上限 ¥20),全零归一告警、零截断。下一候选按 ADR-0010 退路链
   = 工单58(商业 TAB 引擎限时筛选/换源限时检查)+ dolce 适配界面检查;
   VLM 直读若再上,须换读法(如逐小节裁喂+外部拍位骨架锚定),不是调提示词
   能救的量级。

## 实测设置(全冻结,可复现)

- **模型**:`deepseek-v4-flash-vision-exp`(ADR-0010 指定名)。**该名已退役**,
  DeepSeek 官方路由至 `deepseek-flash`(V4.1-Flash-1017,响应体 `model` 字段
  实证),账单按 Flash 价(输入 cache-miss $0.15/M 谷、$0.30/M 峰;输出
  $0.60/M 谷、$1.20/M 峰;本次全部谷时=周日)。1M 上下文 / 384K 输出上限。
- **思考模式**:默认开且 effort=high——首轮调用把 16384 completion 全烧在
  reasoning、正文为空(finish=length)。冻结配置改 **thinking enabled +
  reasoning_effort=low + max_tokens=65536 + temperature=0 + response_format
  json_object**(管线参数,提示词未动),此后 8 调用全部 stop。
- **提示词**:冻结于 `score_workbench/vlm_poc.py:PROMPT`(`PROMPT_VERSION =
  "57-v1"`,中文,含记号系统/拍位锚定(第 n 小节=(n−1)×4,印张自带逐小节
  灰字小节号)/输出契约/unknown 纪律)。批量期零改动,单测钉锚。
- **输入制备**(`vlm-prepare`):谱全了 PDF 每页 2×2 嵌入位图(993×1404),
  **原生分辨率拼装**整谱页(工单56 考古口径,不重采样)1986×1404;系统条带
  = 整块全层裁块(和弦图→歌词,含完整节奏带),300dpi 骨架坐标 ×0.8005 换算。
- **两形态**:整页 = page0/1/2 三页各一次调用(谱页0=小节1-13,谱页1=14-24,
  谱页2=25-36+,印张自带小节号);裁块 = 五系统条带(谱页0 sys0[小节1-5]/
  sys1[6-9]、谱页1 sys4[18-21]/sys5[22-24]、谱页2 sys6[25-27]),各一次调用。
  每单元独立调用,同一冻结提示词。
- **候选归一**(工单56 契约侧):`ukeflow.eval.candidate/1`;duration 按
  「至下一 attack/休止」持续窗重算(与真值同规,模型原值留

### 错误解剖

- **拍位**:空间漂移诊断(±0.35 拍窗)两形态 max|Δ拍| 恰 = 1/4——模型拍位
  全落在 0.25 网格上、自洽,但**累加错**(符杠组漏读/多读一格,后面整小节
  连锁漂移);rhythm_miss(成对但时值错)裁块 82 / 整页 37。
- **漏读**:整页形态候选事件仅 159(真值 324),弦分布 ①54/②38/③39/④28
  (真值 ①88/②81/③87/④68)——**顶线(①弦)系统性漏读**;裁块 227 事件,
  ①弦同样塌(37)。密集 ×堆 段(主歌拨弦型)整列整列消失。
- **音高**:候选事件 (弦,品) 对真值多重集覆盖 0.64(裁块)/ 0.47(整页),
  对候选自身命中 0.92/0.95——**读出来的音大多是印张上真实存在的音**;
  同拍错品(fret_error)仅 14/18,同拍错弦(string_error)40/40。
- **技巧**:卷弦 roll 四处全数检出(裁块),箭头方向 89+ 在待裁定槽外无罚;
  震音/连音×柱可检出但拍位同样漂。休止:整页只报了第 1 小节全小节休止
  (对),裁块多报 3 处休止(把 × 堆空档误判休止)。

## 对 ADR-0010 决策点的回指

- 决策 3(主线=VLM 直读):**首轮实测否定当前读法**,且失败形态(节奏网格
  重建/顶线漏读)提示这不是提示词工程量级的问题。dolce POC 的「裁条塌」
  在 VLM 上不成立(裁块没塌),「整页上下文」也没带来优势。
- 决策 5(退路链):证据支持按序走——工单58(商业 TAB 引擎限时筛选/换源
  限时检查)升为下一优先;「混合读取+校对」若做,形态应是**外部拍位骨架
  (几何管线出小节/拍网格)锚定 + VLM/OCR 只做音位识别**——本轮证明 VLM
  自主重建节奏网格不可行。
- 晋级线语义不变:F1 ≥ 0.90 仍是对任何后续候选的尺子。
