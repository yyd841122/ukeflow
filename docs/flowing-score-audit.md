## 机比方法(beat-id 同源)

原谱 SVG 的音符组 `<g class="b{beatId}">` 与我们 DTO 的 beat **id 完全同源**:
- 逐音核对:导出我们的渲染模型(`flutter test test/dump_render_model_test.dart`
  → `/tmp/our_render.json`),按 id 配对原谱数字的 (x, y→弦行, 值) 逐项对账;
- 数字基线 y → 弦号:staff A `55.44/64.68/73.92/83.16`、staff B
  `69.44/78.68/87.92/97.16`(两套谱表交替);
- 原谱排版实测:小节宽 152.7px、弦距 9.24px、数字 10.92px、播放器流速
  50~62px/s、延音弧=谱面上方双 Q 小弧(源→目标,在按法图带)。

## 已定案的画法(2026-11-09 终版 = 照抄 codex;改动前先读)

- **小节 = 左留白 32 + 内容 + 右留白 24**;小节线画在小节左缘,首音在
  线右 32px——留白即避让,首音永不压线;交界的自然加速与 codex 本尊
  同款(56px 留白在音间窗内跨过,用户接受)。
- 数字 **18px 骑在弦线上**(垂直居中)+ **纸色描边光晕 7px 垫底**
  (codex app.css `.fret{stroke:paper;7px;paint-order:stroke}`)——
  穿过数字的弦线/杆/波浪被光晕就地擦掉,数字永远干净;**这是 codex
  不做避让工程的根基,任何重叠问题先想到光晕,不是挪线**。
- 当弹数字:红 + 加粗(800),照抄 `.fret.active`。
- 符杆:与数字列正中对齐,杆顶 = 最低音弦的下一根弦线(钳到 G 弦),
  垂到符杠(用户定案:比 codex 短桩更向下延伸);延音和弦隐藏数字但
  保留杆。
- 延音记号:谱面上方一枚小弧(源→目标;原谱 alphaTab 亦为逐弦弧,
  用户验收单弧等价)。
- 琶音波浪左伸 17px(泛音 32),波浪右缘微贴自身数字左缘(原谱式微贴)。
- 休止符 Bravura 29px;附点在杆右 x+9+dot×5;符尾 q12,-2 13,-14。
- 每秒像素:竖屏 100 / 宽屏 145(codex 同款规则)。
- 原谱在**换行处补印**延音音的数字;连续流水无换行,保持隐藏。
